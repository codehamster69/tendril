## What was added
- **sim** (`arena.ts`): `challengeSetup(kind, seed, version = SETUP_VERSION)` now returns `{ ticks, setup, modifiers }`. Version 0 (`SETUP_LEGACY`) is the old plain farm; version 1 draws coins (0-60), free research (none/wheat/clover), weather bias (frosty/standard/calm) and tick budget (2400/3000/3600) from the seed. Also `describeModifiers`, `parFromReference`, `MODIFIER_BOUNDS`, `PAR_PERCENT` (90), `PAR_MIN` (60). `Setup.weatherBias` + `World.weatherBias` (optional; absent unless non-zero, also in `serialize`) change only which weather segments are frost (`weather.ts`).
- **spec**: `docs/SIM_SPEC.md` appendix "Challenge modifiers (setup version 1)" holds the bounds, draw order and par rule.
- **server**: migration `005_setup_version.sql` adds `challenges.setup_v` (default 0, so every existing row is legacy). New dailies, seasons and duels are written with 1. `loadChallenge`/`createDuel` call `referencePar` (sends `src/reference.ts`, a copy of `daily.sprout`, to the verify function) and set `par = parFromReference(netWorth)`; any failure keeps `DAILY_PAR` (duel of non-3000 length keeps null as before; version-0 rows never run the check). API now returns `setupVersion` on `/challenges/:id`, duel pages and `/entries/:id/replay` (plus `kind` there). `createApp({ setupVersion })` is a test seam; existing server tests pin 0 to keep their plain-farm fixtures.
- **lang**: verify request takes optional `setupVersion` (absent = 0) and the answer carries `netWorth`. CLI honors `setupVersion` and prints the day's modifiers.
- **client**: `challenge-setup.ts` (`setupOf`, `challengeScenario`) is the one place the client builds a challenge world; header shows "Today: ..." (`#arena-mods`); replay view passes the stored version. Offline fallback daily uses the drawn tick budget.
- **site**: home page "Today's twist" line from the same functions.

## Decisions
- Per-challenge `setup_v` instead of date cutoffs: nothing stored ever changes meaning, and the generator can be revised later as version 2.
- Par is fixed at creation and never recomputed, so a verify outage on creation day leaves that day on 290 (still playable).
- Duel of a daily seed reuses its draw so a duel is the same game as the daily it came from.
