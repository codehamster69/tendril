# U6: sunset result screen

Files: new `packages/client/src/result-screen.ts` (+ `.css`), `result-model.ts` (pure medal/hint/best-line rules, unit tested in `result-model.test.ts`), `e2e/result-screen.spec.ts`. Small edits: `arena.ts` (old `#arena-result` panel, duel panel mount and `showResult` removed; submit helpers kept), `stage.ts` (removed the observer that opened the Arena modal on results), `main.ts` (one mount line), `farm-camera.ts` (`spin`), `farm-view.ts` (`orbitBy`, `lightPreset`), `package.json` (test list).

Decisions
- Run end = `tendril:scenario-end` (daily/season only). Dusk is `view.setLight('night')` set directly because U2's day dial is not merged; the previous preset is restored on Try again or when a new run starts. When U2 lands, swap that call for its `dayProgress`.
- Orbit: one eased full turn (5.2 s) by `orbitBy` per frame, ends where it began. Any key skips; reduced motion skips orbit and count-up.
- Medals: Wealth and Speed come from the exact local replay, Brevity and ranks wait for the server. "Earned by how much" = coins over/short of par, ticks to spare.
- Missed par = gentler card, Try again first, one hint: crashed bot first, else tick of last sale (from P3 `tendril:events`), else last coin growth.
- Personal best is kept per challenge id in localStorage (`tendril.best.v1`).
- Watch replay links to `replay.html?e=<entryId>` (clip export lives there). Share copies the existing share text. Enter = Try again, Escape closes the card (a "Show result" button brings it back).
- The duel panel moved into a "Challenge a friend" fold on the card.

Known: old e2e specs that use `#arena-result` / `#btn-copy-result` fail until U11.
