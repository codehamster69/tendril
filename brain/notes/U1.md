# U1: full-screen game stage

Branch off PR #68 head (`claude/project-thread-ioqf7g`). PR targets that branch.

## Changed files
- `packages/client/src/stage.ts` (new): slate hide/resize, console strip, HUD chips, transport, menu, modal panels.
- `packages/client/src/stage.css`, `hud-kit.css` (new): layout and shared kit. `brain/notes/hud-kit.md` lists the kit.
- `packages/client/src/main.ts`: one import and one call (`mountStage`, last of the mounts).
- `index.html`, `style.css`, `farm-hud.ts/css`, `ui.ts` untouched: the layout is CSS on `body.game-stage` plus DOM nodes moved at runtime. Old ids (btn-run, speed, hud-*, decks, lesson-card) still exist, so existing modules keep working.

## How it works
- Canvas fills the window (`#farm-stage` fixed). Slate is `#side` fixed right; width in `--slate-w`, saved as `tendril.slate.width`; hidden state `tendril.slate.hidden`; Ctrl/Cmd+E toggles (capture phase, so Monaco does not eat it).
- Transport buttons click the existing hidden controls (`#btn-run`, `#btn-pause`, `#btn-step-line`, `#speed`); Run to sunset calls `loop.runToEnd()` (needs a tick limit; disabled in sandbox). Live farms show only play and Step. Space toggles play unless focus is in an input, button, editor or dialog.
- Menu entries move the old nodes into a modal (`Panels`) and put them back on close: Inspectors (forecast + deck-farm), Progression (research + achievements), Arena & lessons (`#lesson-card`), Market, Minimap. Duels, Rating, Account, Reference click the old buttons. The arena result opens its modal on its own.
- Old top bar is hidden; mode tabs, leaderboard, docs and account button live in the menu.

## Decisions
- Debugger: kept as the second tab of the slate's output strip (a modal would cover the farm while stepping); the menu entry opens the slate on that tab, and a breakpoint pause does the same.
- Step = one line (F10), as before. "+100 ticks" is no longer reachable by button; Run to sunset covers fast forward.
- Status bar stays as a thin strip at the bottom.
- Editor focus after Ctrl/Cmd+E uses the Monaco textarea (`editor.ts` is P1's, so no API added).
