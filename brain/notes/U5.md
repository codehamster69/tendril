- New: `menu.ts/.css` (full-screen menu), `start-card.ts`, `settings.ts` (values, storage, apply), `settings-panel.ts` (screen body), `settings.test.ts`, `e2e/menu.spec.ts`.

## Decisions
- Esc opens/closes the menu everywhere (capture phase). It yields to dialogs, panels and editor autocomplete. In Settings, Esc goes back to the menu first.
- Pause: sandbox, campaign and daily runs pause while the menu is open and resume on close. Endless is wall-clock, so it keeps running.
- Start card: daily, season, duel and campaign only (Endless and Sandbox have no day). Shows again after Reset to tick 0. Enter starts.
- Settings key `tendril.settings.v1` {muted, volume, quality auto|low|high, motion system|reduced|full, fontSize}. Event `tendril:settings`. P4 reads `quality` (also `html[data-quality]`). U4 reads `muted`/`volume`. Editor font via `--editor-font`.
- Status lines: daily and season show number, par, players from the API. The client has no streaks or medals yet, so none are shown.
- Seed catalogue entry is disabled until U8 calls `setEntryAction('seeds', fn)` on the menu api. Profile opens the rating card.
- Campaign appears as "Lessons".
- 2026-11-17 wiring fix: sound, graphics quality and reduced motion now actually follow these settings. Animation code reads `motionQuery.matches` (settings.ts) instead of `matchMedia('(prefers-reduced-motion: reduce)')`, and CSS uses `html[data-motion="reduced"]` instead of the media query, so "Off" overrides the OS. e2e/menu.spec.ts asserts the real effects.
