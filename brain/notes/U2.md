# U2: day dial and living sky

Branch `claude/u2-day-dial`, PR targets `claude/project-thread-ioqf7g`.

## Changed files
- `day-clock.ts` (new, pure): `dayProgress(tick, runTicks)` is the single clock. Run with an end: tick / limit. Endless and sandbox: loops every `ENDLESS_DAY_TICKS` = 3600. `day-dial.ts` re-exports it. It lives in its own file so node tests can load it without CSS.
- `day-dial.ts` / `day-dial.css` (new): arc dial, top centre of the free stage area (shifts with the slate). Weather segments and order deadlines are focusable marks with a tooltip (hover or focus, Esc hides). Label is "Tick n of N", or "Day d · tick n of 3,600" when looping.
- `farm-light.ts`: new preset `'day'` (now the default and the HUD's default). `setDay(progress, jump)` blends dawn, noon, golden, dusk keyframes (`dayLook`). Target recomputes only every `SKY_STEP` = 0.01 of progress, then the existing easing applies. A scrub or first frame (`jump`) skips easing so sky and dial agree. Rain also gets a slow cloud-shadow dip in sun intensity (intensity only, no shadow redo; off under reduced motion).
- `farm-view.ts`: `setDay(cfg)`, `syncDay()` called from `update()`; feeds the light and the dial from the same `dayProgress()` call.
- `farm-hud.ts`: mount line, "Day" entry first in the light popover, default 'day' unless the player saved another look.
- `main.ts`: one `view.setDay(...)` line. `replay-main.ts`: one line with the replay length (sky only; replay views have no HUD).
- `day-dial.css` pushes `#stage-tools` down 96px so the toolbar does not sit on the dial (U5/U7 will rework that row).
- `package.json`: adds `day-clock.test.ts` to the test script.

## Decisions
- Weather marks come from the same weather schedule the sim uses (a scratch world from the farm seed and `weatherBias`), so future weather shows on the dial before it arrives. Weather only depends on seed and bias, not on actions. Ranked Endless farms have no bias. Order marks come from the snapshot orders (deadline inside the shown window).
- Fixed looks (Dawn, Noon, Golden, Night) still exist as overrides.
- Sunset is dusk (golden mixed 55% toward night), not full dark.
- Looping wrap (progress 1 to 0 in Endless) eases from dusk to dawn instead of cutting.
