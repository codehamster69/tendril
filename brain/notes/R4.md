## Decisions
- **Seen state is client-side, per user** (`tendril.rating.seen.<userId>` in localStorage), set when the card is shown, so a reload never repeats it. The client calls `/ratings/me/latest` WITHOUT `seen` (so the chip always has data) and compares the id itself. Clearing site data shows the latest card once more.
- The chip shows the overall rating (`1,642 Bloom`, `?` while provisional). It is hidden when signed out or never rated. Clicking it reopens the last result (not a link: the desktop app only opens a fixed list of site pages, so `/u/<login>` is not opened from here). The share text does end with `tendril.hokora.xyz/u/<login>`.
- One card serves both moments: heading "Yesterday" (or "Last result" from the chip), or "Promoted to <Tier>" with a thicker tier-coloured border when any discipline's `promoted` is true. Speed/Brevity changes appear as extra lines.
- Result-panel line only for signed-in daily/season with number > 0 (rated play starts 1 Dec; practice and duels never rated). It follows the entry's `parTick` (server value after submit, local before).
- Card label is "daily 4 Dec" / "weekly season" (derived from challengeId; no challenge number in the API).
