## Interface for H4, H5, H9, H10 (all exported from `@tendril/sim`)
- `challengeSetup(kind, seed, SETUP_PICTURE)` returns `{ ticks, setup, brief }`; `brief.goal = { kind: 'picture', budget, picture: { id, w, h, title, cells } }`. `setup.plots` holds the extra plots (flat), `setup.goal` the same goal, so `createWorld(farm, setup).brief.goal.picture` is what Sprout and the HUD read.
- `cells`: string of `w * h` digits, row-major from tile (0,0); `PICTURE_PALETTE[code]` names them: 0 grass, 1 soil, 2..7 carrot..apple (code = crop id + 1), 8 barn. Pixel `(x, y)` is world tile `(x, y)`.
- `pictureCodes(world, picture)`: what the farm shows under each pixel now (9 = building or unowned), for the HUD diff, a Sprout `picture_diff()` and the timelapse. `pictureScore(world, picture)`: the permille now. `tileCode(world, x, y)`: one tile.
- `replayWithGoal(world, log, toTick, goal, par)`: `score` is the permille at the end, `parTick` first time at par. Cheap (about 2 ms per replay).
- `pictureActive(date)`, `setupVersionFor(date)`: version 3 only from `PICTURE_EPOCH`. Server code that tests `setup_v >= 2` already treats 3 as a brief; `daily-pages.ts` compares `setup_v === SETUP_BRIEF` and will need `>= SETUP_BRIEF` (H5/H4, not touched here).
- To flip it on later: set `PICTURE_EPOCH` to a date after the reference program (H4) sets `BRIEF_FLOOR.picture`; rows already stored keep their version.
- Reference programs and par for the picture goal: H4. `pickBrief` accepts a `version` argument for it.

## Decisions (reasons)
- Weights: wealth 3, picture 4, the other four 3 each, out of 19 (0.21 per day). 16+1 in the brief did not add up, so I took the table in the brief literally. Seasons keep the old table so a season never needs a picture of up to 4 plots plus its twists.
- Palette is 8 colours: soil is "tilled or growing", grass "untouched or harvested". A harvested annual is grass again, which is the real puzzle (leave ripe crops standing).
- Score formula as briefed (matches over all pixels, barn pixel counted as a match). To stop do-nothing wins, every pool picture has at most 40% grass and 45% soil (test).
- No `land` or `hive` twist on a picture, and a locked research never removes a crop the picture needs (the picture is drawn after the twists and filtered).
- Apple is rare (20 of 178 pictures, never in glyphs): 900 coins of research is too much for a daily with no coins at the start. Pumpkin appears in 88, berry in 50; H4's reference should show whether that is playable; if not, drop `p`/`b` usage in the pool or lower the picture odds.
- Glyphs are 1 draw in 5 so the pool, at about one picture day in five, lasts well over a year before a repeat and glyphs fill the gaps.
