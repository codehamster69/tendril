## How it works
- No extra replay: `AwayFacts.record` counts sold units per item and each bot's last action tick from the action log every step already returns (lean steps included). Lean mode skips view events, so the log is the source.
- Away time = ticks behind at the first snapshot + ticks the server rested (`restedAway`). Under 6,000 ticks (10 min): no card, counting stops.
- Coins = snapshot coins at the end minus at the start. The card shows when the farm is within 30 ticks of the clock, or at the first script error (the loop halts the run there).
- Problem line: first error ("Bot 2 stopped at line 14 at tick 8,412: not enough coins") with a Show line button (`editor.revealLine`); else the bot idle longest, 5+ minutes.
- Cap line: "Your farm stopped growing 2 h ago: it rests after 6 h away." The existing "Your farm rested" toast is kept.
- Nudge line: today's daily number and goal (`api.challenge`, skipped offline) and the streak. "Gemini scored X" skipped: H1 not merged.
- Streak: `/players/:login` `streak.current` (same as the README badge), via `/me`, once per page; shown on the card and next to "Play" in the menu. Signed-out players see neither.
