## Decisions
- Test lives in `packages/rating/test` because the site has no test runner and root manifests are coordinator-owned. The site does not depend on `@tendril/rating`; the docs numbers are a copy guarded by the test.
- Light tier colours are darkened from the mockup (seedling, shoot, vine, orchard, grove failed 4.5:1 on panels); dark values are the mockup's. Evergreen = deep green with a gold underline.
- Colour is never the only signal: Tier column text, `title` with the tier name, signed +/- text on changes.
- Closed-board decoration comes from R2's `/challenges/:id/board`; the Daily/Week tabs show today's open board, so changes appear on yesterday's winners and the fold-out board.
