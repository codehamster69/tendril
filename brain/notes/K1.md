## Contract changes
1. `Twist` has an optional `item` (stock twist only).
2. `challengeSetup` has a sixth optional argument `source: 'daily' | 'season'` (a duel copies its source's brief).
3. `weatherBias` takes 2 (drought) and -2 (hard frost) and the world keeps `brief` (not hashed). `ChallengeSetup.brief` is absent (not null) for versions 0 and 1.
4. `setupVersionFor(date)` added for K3.

## Decisions (D-K1) and things to know
- No RULES_VERSION bump: every new input is an optional Setup field and absent means no change. All existing tests and golden hashes pass unchanged.
- Drought keeps the same random draws but gives each rain segment length 0, so later segments (frost) shift in time. It is deterministic per seed; it is not "standard frost with no rain".
- Festival counts *deposited* units (barn or silo), as the contract says, so selling does not lower it. Quota sizes (`QUOTA_UNIT`) are first guesses: K2 must calibrate them against its reference program and the reroll rule.
- The hidden-farm difference comes from the world seed only: soil patches, weather, orders and the inherited farm's layout. Starting land, hive tile, caps and quotas are fixed by the brief seed.
- Net worth based scores can fall (sellPlot, clearing a silo), so par is "first tick at or above par".
- Client note for K6: the Sprout/UI cost helpers (`botCost`, `plotCost`) do not know the caps; a capped `buyBot` just returns 0. Snapshots do not carry the goal; read it from `challengeSetup(...).brief`.
