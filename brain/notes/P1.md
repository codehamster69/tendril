# P1: Monaco replaced by CodeMirror 6

Files changed: `packages/client/src/editor.ts` (rewritten), `package.json` + `pnpm-lock.yaml` (monaco-editor out, @codemirror/* and @lezer/highlight in), `src/style.css` (removed the editor decoration block, now in the editor's own theme), `src/farm-hud.ts` (focus guard selector), e2e specs that looked for Monaco DOM.

Decisions
- Colouring: a CodeMirror StreamLanguage fed by `KEYWORDS`, `CONSTANTS` and `API` from `@tendril/lang`, the same lists `monarchTokens()` reads, so they cannot drift. `monarchTokens()` stays in lang untouched (lang is off limits).
- `Editor` interface unchanged except `showBotLines(debug, paused?, colorOf?)`: new optional colour function, default is the old `BOT_COLORS` cycle.
- Line and gutter marks use a `--mark` CSS variable, so any colour works.
- Sizes: editor.ts bundled alone with CodeMirror is 389 KB raw, 129 KB gzip. Total script across the build dropped from 5.1 MB to about 1.3 MB.
- No Vite or Electron config referenced Monaco workers beyond editor.ts itself (the `worker` option in vite.config.ts is for the sim worker and stays).
- Root override for Monaco's DOMPurify (D-014) is no longer needed; left for the coordinator to remove.
