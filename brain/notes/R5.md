## Routes (all public GET, 1 hour: `public, max-age=3600, s-maxage=3600`; unknown login is still 200)
- `/api/card/:login.svg`: 460x150 dark card. No script/style/image/link/href/url()/external ref (asserted by regex in a test). Query strings -> 400 like the existing badge.
- `/api/badge/rating/:login.svg`: `1,842 Orchard`, tier colour; `placement n/5`, `unrated`, `unknown player` grey.
- `/api/og/u/:login.png`: 1200x630 PNG, ~10 KB. Rated, placement (provisional, dim), unrated, promotion, unknown (reuses the generic card). Query string -> 308 to the clean URL, as for `/og/:id.png`.

## Decisions
- Promotion variant: newest overall result crossed a tier floor upward, player out of placement, closed less than 7 days ago (`PROMOTION_WINDOW_MS`). Older promotions would mislead on a link preview.
- Mosaic is that of the latest rated overall entry (promotion = the farm that earned it); unrated players use their latest entry.
- No hit counting for these routes (share_hits is per entry).

## Caveats / requests
- SVG was not rendered by a real renderer (none installed) and not tried inside GitHub; it is well-formed (xmllint) and uses only rect/text/polyline/title with generic fonts.
- Mockup says "every point links to a replay": not possible in an `<img>` SVG, omitted.
- Pasted links assume `/u/<login>` (R3) and `/docs/rating/` (R6) exist; R3 should point og:image of the profile at `/api/og/u/<login>.png`. Without a vercel.json rewrite only `/api/...` URLs work (the docs use those); a bare `/og/u/` or `/card/` public URL would need a rewrite (coordinator owns vercel.json).
- Card text uses the host `tendril.hokora.xyz` hard-coded; PNG uses the request host.
- Cards reflect the rating as of the last lazy rater run; the CDN adds up to an hour.
