## Behaviour
- Rival = best model row of `GET /challenges/:id/board?author=model&limit=5`, by `score ?? value` (visible-farm goal score on brief days). Only real dailies (not practice, offline, season or duel).
- Start card: model line, or "The machine plays at 6:10 am IST" (viewer's zone) until 00:40 UTC, "is playing now" for an hour after, then nothing. A failed read shows nothing and never blocks Start.
- Goal HUD (brief days only; classic dailies have no HUD): marker on the bar, name and score line, "passed" in green once beaten; festival (no bar) gets the line only.
- Result: line under the rank; both final scores compared when both are final, otherwise visible farms, worded "on the visible farm. Provisional until the day closes."; share text gets `🤖 Beat Gemini by 14% on the visible farm`.
- `/bench/`: tally of closed days with both bests final, table with goal name, `*` marks visible-farm-only numbers.
- Workflow: with `MODEL_RUNNER_MODELS` unset, behaviour is as before (one model). Pairs `gemini:` and `anthropic:` only (the harness supports those two). A manual run with a model input plays only that model. A failed pair is reported after all pairs have played.

## Decisions
- Same-user problem: the board keeps one row per player, so models running under `tendril-models` collapse to the best one in the start card; `/bench` lists each. Fine for "beat the best machine".
- `/bench` counts a day only when closed and both bests are final, so the tally never flips mid-day.
- New cached read instead of 28 board calls from the site page.
