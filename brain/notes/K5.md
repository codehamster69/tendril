# K5: Sprout brief queries
`goal() quota(item) budget() twists() bot_cap() plot_cap()`: free queries, feature `queries` (no lesson gate in the arena).
Implemented in `packages/lang/src/brief.ts` (one adapter), used by `interpreter.ts` and `compiled.ts`. Neutral values with no
brief: wealth / 0 / 0 / [] / none / none. Covered by `test/brief.test.ts` (both engines + world hash) and
`examples/brief-reader.sprout` (equivalence suite).

**Assumed K1 world fields (rebase check):** `world.goal {kind,budget,quotas?}`, `world.botCap`, `world.plotCap`,
`world.twistKeys: string[]`, `world.deposited: number[]` (units deposited per item, for quota). If K1 names them differently,
edit only `brief.ts` and the test's `briefWorld` stub.

**Gotcha:** the six names are now reserved (built-ins can't be variable names). A stored program using `goal`, `quota`,
`budget` or `twists` as a variable would stop compiling. None in repo examples, lessons or tests.
