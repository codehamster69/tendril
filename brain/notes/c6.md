# C6: Daily winner bot

## Files
New: `.github/workflows/daily-post.yml`, `scripts/daily-post.mjs`, `scripts/daily-post.test.mjs`, this note. Nothing else touched.

## Behaviour
- Cron `10 0 * * *` (UTC) plus manual `workflow_dispatch` with optional `date` (YYYY-MM-DD). Default is yesterday UTC.
- Script reads `GET /api/challenges/d-<date>` and, if `players > 0`, `/board?medal=wealth|speed|brevity&limit=1`. Posts winner, value, mosaic and `/r/<entryId>` per medal. Model entries are labelled `(model: name)`.
- No farms or unknown challenge: a short "no farms yesterday" message. Pre-launch dailies (number <= 0) omit the `#n`.
- `DISCORD_WEBHOOK_URL` unset: prints the message, exits 0. Webhook error or API error: exits 1 (the Action fails visibly). `allowed_mentions` is empty so player names cannot ping. Message cut to Discord's 2,000 chars.
- `TENDRIL_ORIGIN` overrides the default `https://tendril.hokora.xyz`.
- Not load-bearing: a missed run just means no post; rerun with `date` from the Actions tab.
