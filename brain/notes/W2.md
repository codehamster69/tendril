## Behaviour
- Panels: Farm, Code, Console, Debugger, Orders (goal card plus achievements), Reference, Bots (new list: colour, position, doing), Inspector (mirrors the pinned tile), Market, Map, Settings. Farm and Code cannot be closed.
- Presets as in the approved design (Farm first is default). Saved under `tendril.workbench.layout` (`{v:1, layout, panels}`); bad data, a wrong version, an unknown panel, or a missing Farm or Code falls back to Farm first.
- Ctrl or Alt + 1..9 focus (Farm, Code, Console, Debugger, Orders, Reference, Bots, Inspector, Market), Ctrl or Alt + W closes the focused panel, Ctrl/Cmd + E focuses Code, double-click a tab maximises.
- Phone (under 760 px): farm on top (40%, divider drags, 20 to 70%), one panel below, bottom tab row; own saved tab and split. Resizing across 760 px switches modes live.
- Pop out is not shown (W4).

## Decisions
See D-W2 in `brain/DECISIONS.md`. Details worth knowing:
- Default `onlyWhenVisible` rendering. The `always` renderer positions panels with async overlays and left Farm, Code and Console blank after a preset change in the real browser. Instead each panel's content node is parked in `#wb-park` whenever its tab is hidden or the panel is closed, so every `getElementById` call in other modules still works. (Detaching the nodes broke a reload with Settings in front of Code.)
- Transport sits at the bottom of the farm panel (not in the Code header) so Run stays reachable when Code is stacked behind another tab.
- Run controls and the examples picker stay where they were; `#code-actions` in the Code heading is an empty slot for W3's editor settings button (W3, PR #137, mounts it inside the editor container, so there is no conflict, but it can move into the slot).
- The mode caption is hidden on phones to give the island room.
