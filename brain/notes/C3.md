## Behaviour and decisions
- Worker runs player code only through `@tendril/lang` (`compile` + `createRun`). `setSource` with errors returns diagnostics and keeps the old run. `resume` finishes the interrupted tick (`run.step(1)`). The pause is kept across commands until a command runs ticks, so `flush` does not lose it.
- Breakpoint stops can land inside tick T after other bots (or farm actions) already acted. That world cannot be replayed from a log. RealSim therefore holds the actions in memory and does not checkpoint until the tick completes (`held` in real-sim.ts); the durable save and hash chain stay on the last complete tick. Test: "stopping inside a tick keeps the saved log replayable".
- GameLoop is DOM-free: constructor `(sim)`, `init(scenario?, source?)`, `sourceProvider` (editor registers it so Run/Step always use the text on screen), `startScenario`, events as in CONTRACTS plus two extras: `tendril:source` (loop changed the program text; UI syncs the editor) and `tendril:notice` (console info/err/clear). `tendril:status` carries extra fields (`state`, `save`, `can*`). `loop.reset()` never prompts; the Reset button confirms in live mode.
- Live mode: the clock is the only source of ticks; when behind, the loop catches up at up to 2,000 ticks per frame regardless of the speed selector (the selector is inert in live). Previously speed scaled the catch-up rate.
- The first script runtime error halts the run (status `error`, "Bot N stopped on line L") as the old Lua flow did. Run after an error recompiles (every bot restarts, farm kept). A compile error while running keeps the previous program running.
- The frame loop renders before stepping; otherwise a breakpoint reply raced one more step through the breakpoint.
- Console 500s: the page asked `/api/me` on every load and the proxy answers 500 when no server runs. It now asks only if a token or the `tendril.signedin` marker exists.
- Renderer: crops 1..6 (berry, apple), `prop_beehive`/`prop_compost` buildings, honey marker on hives, one marker per carried item kind above each bot. Models that are not exported yet (apple stages, `item_*`) fall back to placeholders with no console output. farm-view.ts is 434 lines (was 511); other files are at most 343.
- Electron: the built client is served from `app://tendril/` (privileged scheme, path-clamped handler in `app-protocol.cjs`). `entryURL` no longer takes `indexPath`.
- Storage keys keep the `sprout.v1.<mode>` namespace (deliberately separate from legacy v2 saves); tests now read those prefixes.
