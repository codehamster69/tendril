# B4: Share links and preview cards

## Files
- New: `packages/server/src/share.ts`, `packages/server/test/share.test.ts`, this note.
- Edited: `packages/server/src/app.ts` (one self-contained block after `new URL(...)` plus `publicOriginOf`), `vercel.json` (one rewrite).

## Behaviour
- `GET /r/<entryId>` (also `/api/r/<id>`): 200 HTML with Open Graph + Twitter tags, meta-refresh to `/play/replay.html?e=<id>`. Unknown or malformed id: same page with the generic card and a link to `/play/`. Cache `s-maxage=300`.
- `GET /api/og/<entryId>.png`: 1200x630 PNG (about 10 KB), drawn in `share.ts` with a 5x7 bitmap font and node:zlib, no image dependency. Mosaic tiles, title (DAILY #n / WEEKLY #n / DUEL), net worth, top-percent, par, player. Unknown id: generic card, still 200. Cache `s-maxage=86400`.
- Origin for absolute URLs: `PUBLIC_ORIGIN` if set, else the request origin.
- Hit counts: table `share_hits(entry_id, day, kind page|card, hits)`, created lazily with CREATE TABLE IF NOT EXISTS (no migration number, so no clash with B5/F2). Counted only when the function runs, so CDN-cached hits are undercounted; `s-maxage` is short on the page for that reason.
- Top percent = 100 - percentileOf(rank, total) + 1 on the wealth board (rank by each player's best net worth); hidden when only one player.

## For the coordinator
- The redirect target is B2's replay page, `/play/replay.html?e=<entryId>`.
- Fonts are upper case only; characters outside the glyph set show as `?`.
