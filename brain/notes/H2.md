## Behaviour
- Running farm + 600 ms without typing + meaningful, parsing change = `compile` in the worker, bots restart from the top, farm kept, resumes. Busy loop: retries every 150 ms (up to 6 s) so an edit is never lost.
- Comments, blank lines, spaces between words: ignored. Indentation and string contents count.
- Stopped, paused, ended or at a breakpoint: nothing applies; Run stays the button. Setting off while running shows "Edited · press Run to apply".
- Typo: diagnostics underline the line (editor `data-error-lines`), chip "Still running your last working code", farm status stays running.
- Rated days: the server verifies the program by replaying the submitted actions (K3: `mismatch` when code changed mid-run), so a run edited after tick 0 on a non-practice challenge shows "You changed your code during this run..." and a primary "Re-run my final code from the start" (reset, then run). The first score still submits and counts, only Brevity/rating need the verified program. The same card shows if the editor no longer holds the code that ran. Endless farms (live) never count as mid-run: they have no tick-0 program to verify.
- Breakpoints and line stepping: unchanged paths (applyLive only fires while `running`, which a breakpoint pause clears). integration.spec breakpoint tests pass.
