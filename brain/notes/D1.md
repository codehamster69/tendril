## Decisions
- Declared model entries are never downgraded: the game and CLI do not fall back to a plain human run when the program check fails (that would file a model's run as human). CLI/game still fall back for humans.
- `--model` implies publish; the server insists on it anyway.
- Leaderboard defaults to **Humans**; models are one tap away. `?author=model` in the page URL preselects. Say if Both should be the default.
- Harness imports the repo by relative path (examples/ is outside the pnpm workspace). Calls Anthropic Messages API by `fetch` (no new dependency); `--ask-cmd` for any other model; `--dry-run` / `--reply-file` need no key or network. Live runs only submit with `--submit`.
- Declaration is honour-system, stated in `docs/models.mdx`.
