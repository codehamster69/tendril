## Decisions
- Name policy is enforced at write time (column = login, migration rewrites old rows), so every existing route is covered without touching each query. The `displayName` JSON key stays for old clients and always equals `login`. A test walks 13 routes and checks that.
- A report is `counted` when filed: account at least 7 days old AND at least one entry with a replayed log. Stored once, so hiding is a plain count and never changes with time. Uncounted reports are accepted silently (no signal to abusers).
- Only published, verified programs of other players can be reported (404 otherwise, 422 for your own). One report per account per program; repeats are no-ops.
- Hiding is derived (no flag column), so no ALTER TABLE; un-hiding is deleting report rows by hand.
